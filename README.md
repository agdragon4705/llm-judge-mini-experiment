# LLM 평가자 vs 사람 평가자: 번역 품질 채점 비교 (미니 실험)

> 소규모 실험입니다. 30문장, 사람 채점자 소수, 같은 계열 LLM만 사용했습니다. 결과는 결론이 아니라 관찰입니다.

## 질문
LLM이 번역 품질을 채점하면 사람 채점과 얼마나 일치할까? 어떤 유형에서 후하거나 박하게 채점할까? 프롬프트를 고치면 편향이 줄어들까?

## 데이터
- 영어 문장 30개: 뉴스 10, e스포츠 중계 10, 일상 대화 10 (`data/scores.csv`)
- 한국어 번역: 구글 번역 (수정 없음)
- 채점 기준(1~5점, 정확성 중심): 5 = 의미 완전 보존·자연스러움, 4 = 의미 정확·사소한 어색함, 3 = 일부 오역/누락, 2 = 중요한 오역, 1 = 뜻 거의 전달 안 됨 (`prompts/rubric_for_human_raters.txt`)

## 방법
- **채점자**
  - 나(rater1): 기준표대로 채점, LLM 점수를 보기 전에 완료
  - 친구(rater2): 기준표를 받았지만 실제로는 "읽었을 때 불편하지 않으면 5점"이라는 자기 기준을 사용
  - LLM: Claude. 원래 프롬프트 3회(`prompt_A_original`), 점검 항목을 추가한 프롬프트 2회(`prompt_B_checklist`)
- **블라인드**: LLM에는 사람 점수를 주지 않았고, 사람은 LLM 점수를 보기 전에 채점했습니다. 반복 채점은 이전 점수를 모르는 새 인스턴스에게 채점용 파일 하나만 읽게 지시했습니다(기술적으로 완전한 차단은 아님).
- **분석**: `src/analysis.py`(나 vs LLM), `src/multi.py`(채점자 여러 명 + LLM). 스크립트 초안은 Claude가 작성했고, 후한 문장 비율을 구하는 줄은 내가 직접 추가했습니다.

## 결과

### 나 vs LLM (원래 프롬프트 첫 채점)
| 지표 | 값 |
|---|---|
| 정확히 같은 점수 | 50% |
| ±1점 이내 | 90% |
| LLM이 나보다 후한 문장 / 박한 문장 | 40% / 10% |
| 평균 점수 | 나 4.00, LLM 4.47 |
| 장르별 평균 차이(LLM − 나) | 뉴스 +0.1, e스포츠 +0.4, 일상 대화 +0.9 |

### 사람끼리도 기준이 달랐다
| 비교 | 평균 점수 | 정확히 같은 점수 |
|---|---|---|
| 나 vs 친구 | 4.00 vs 4.83 | 33% |
| LLM(평균 4.47~4.49)은 나보다 후하고 친구보다 박했다 | | |

친구는 30개 중 26개를 5점으로 채점해서(천장 효과) 순위 상관은 의미를 두기 어렵습니다. "LLM이 후하다"는 결론은 기준으로 삼는 사람에 따라 달라졌습니다.

### 프롬프트 수정 실험
| | 평균 | 나와의 평균 오차(MAE) |
|---|---|---|
| 원래 프롬프트 (3회 평균) | 4.54 | 0.77 |
| 점검 항목 프롬프트 (2회 평균) | 4.40 | 0.83 |

점검 항목(시간·수량·부정, 주어·대상, 전문 용어, 추가된 내용, 뉘앙스)을 넣었더니 후한 정도는 조금 줄었지만(0.14점) 사람 점수와의 일치도는 오르지 않았습니다. 같은 프롬프트로 다시 채점해도 약 20%의 점수가 달라졌습니다.

### 대표 사례
- 25번: "tonight"가 "오늘은"으로 번역돼 '밤'이 빠졌습니다. 나는 3점, LLM(5회 모두)과 친구는 5점이었습니다. 점검 항목 프롬프트도 잡지 못했습니다.
- 11번: "flash"(점멸)가 "순간이동"으로 번역됐고, 나·LLM·친구 모두 낮은 점수(2~3점)를 줬습니다.
- 16번·26번: 나는 2점을 줬지만 친구와 LLM은 5점이었습니다. 내가 지나치게 엄격했을 가능성이 있습니다.

## 한계
- 30문장, 사람 채점자 소수, 같은 계열 모델 하나만 사용
- 친구는 기준표 대신 자기 기준을 사용했고 5점이 대부분이라 비교에 한계가 있음
- 텍스트 번역만 다룸 (음성 인식·음성번역, 언어쌍, 잡음 조건은 다루지 못함)
- 사람 점수도 정답이 아님

## 다음에 해 보고 싶은 것
채점 지침을 더 구체화한 채점자 늘리기, 예시를 넣는 few-shot 프롬프트 비교, 다른 LLM 평가자와 비교, 음성번역 결과에 같은 방식 적용

- `src/`: 분석 스크립트 (`python src/analysis.py data/ratings_me_vs_llm.csv`, `python src/multi.py data/scores.csv`)
